## 公共段：笔触与媒介克制（三风格通用，S2/S3 仅媒介语言不同）

> 本节是全技能"笔触克制"的源头定义，Style-2/3 同样遵守、仅媒介不同（S2=水彩蜡笔+编排，S3=色粉油画棒干擦）。下列每条均可回溯到 `_archive/analysis/` 中的参考图。

### 1.1 纸面与媒介
画在带明显压纹的水彩纸/棉纸上，色面"长在纸纹里"、非光滑数码；以透明水彩薄涂为骨，混入蜡笔/色粉笔的干笔颗粒、飞白与颜料沉淀——水彩为底、蜡笔增触感；气质松弛稚拙（naive, picture-book），不写实、不精致描线。

### 1.2 上色＝平涂色块主导
每个部件基本就是**一块固有色平涂色面**，靠一块块色块拼接造型；色面内允许"一遍画成"的自然水痕、沉淀与干笔颗粒斑驳，但**禁多层渐变渲染、细碎排笔、反复叠笔/叠擦磨细腻明暗**。

### 1.3 光影近乎平光、用笔最省
不做三面五调的系统明暗，很多对象只有一块色；体积只靠三件小事——①一块略深的同色色面交代侧面/背光/交叠，②蒂部或受光处**一笔小范围湿接暖色**，③一两个点到为止的小高光点（不全员油亮）；**无大片明暗转折、基本不画落地投影（至多极淡一块接触色）**。概括而不平、有体积不写实；既忌死平涂，也忌用笔触堆出细腻光影。

### 1.4 轮廓默认"零描边"、色块成形
**不画深色或封闭的外轮廓线**，靠色块自身边缘成形；边缘是手绘微抖的**水彩洇染虚边 / 水痕 / 轻飞白**，不是光滑矢量边。只允许三种"线/边"，且都不是光滑细黑描边：
- a. **同色水彩宽带勾边 ＋ 内部留白**（洋葱圈、荔枝壳、翻开的果皮），笔带粗、有粗细变化、边缘洇虚；
- b. 边缘**断续点线 / 短虚线**（荔枝瘤、榴莲刺沿边）；
- c. **同色系一根粗笔触 / 窄色带**分内部结构（腿、果棱、叶脉），数量极少。

### 1.5 分界与交叠不用黑线
相邻色块用**纸白缝隙 / 留白细线**，或**一块略深、略饱和的同色色面**分开（这也是接触阴影/AO 的画法）；前后层次靠色面深浅、冷暖的轻微差别（前实后虚、前暖后灰），不靠透视光影。

### 1.6 细节一律点到为止
籽、刺、斑点、果点、瘤、瓤、果仁、叶脉等，全部用**同色系更深的小色点或短笔触**概括；白色/浅色部位（白果肉、壳、果瓤、眼白、车窗）**直接留纸白**，或极淡彩一块晕染柔接；内部层次用**留白细线/留白弧**；不主动加纤毛、水珠、疤痕等碎节（用户点名才画）。

### 1.7 造型与点缀
造型圆润、憨厚、稚拙、几何概括而微不规整，平光、安静、松弛、有手作温度；**允许高饱和的童趣变体**（近乎纯色平涂），但仍守平涂概括、不做渐变。炭黑/蜡笔粗糙黑线**只用于小面积线稿图标、图章、标签点缀**，绝不勾主体外轮廓。

### 1.8 边缘虚实
默认与可选规则统一见 LAYOUT §4.3（默认主体也湿画洇边柔化、形可辨，次元素再柔一档，点名才不柔主体）。

### 1.9 状态叠加（三风格通用）
可切割主体（水果/蔬菜/鱼肉/奶酪/面包/肉类等）默认随机选用一类状态对（共8种）：整颗+剖半(halved)、整颗+切片(sliced)、整颗+切大块(cubed)、整颗+切小丁(diced)、整颗+切条/切丝(julienned)、整颗+剥皮(peeled，软皮)、整颗+剥壳(shelled，硬壳/虾/蟹/贝/坚果)（如完整三文鱼+三文鱼片/块/丁/条）。状态叠加的两部分**算一个主体类别**（不破坏主体唯一性，不算两个配角），必须同主体、同色系、有物理接触（同一承载面、相邻摆放），剖面/切片/切块露内部结构（籽、果肉纹理、汁液、肉质纹理）。状态叠加仍守笔触克制——平涂色块成形、零深色封闭描边、近乎平光，不因多了剖面而增加多层渐变渲染或细碎细节。不可切割主体（器物/花卉/分子结构等）保持单一自然状态。可用状态类型以旬物索引JSON中该条目的cuttable_states字段为准。

## Style-1：水彩蜡笔手绘

> 单体大留白海报倾向。媒介=透明水彩薄涂为骨＋蜡笔/色粉笔干笔颗粒。

**四种典型版式视觉锚点（校准手感用）**
- 标准居中式（如榴莲）：单体或"整颗+切块"居中偏上，打字机次要文字在上、主标题在下；
- 竖叠罗汉式（如洋葱）：同类 2–3 个垂直叠成塔，超大同色手写标题压顶；
- 散点收藏式（如网袋杂果）：多元素沿隐形 S 形/对角错落、疏密不均，打字机长诗嵌入留白；
- 中文竖排式（如荔枝）：主标题中文竖排于一侧、配一枚红色篆字小印章，可整颗+半颗同框。

### S1-2 颜色（Style-1 专属手法）
- 背景纸色倾向与深浅分情况**唯一权威见 LAYOUT §3**；Style-1 常用白棉纸/水彩纸近白 #fafafa，少数情绪变体用冷灰紫纸 #e5e3e6。
- **色块晕染（Style-1 专属）**：背景不死板平涂——在主体周围加 1–2 块大幅、柔边、洇开的水彩色块（主体色淡化 70%–85%），如葡萄旁一抹淡苔绿水痕；融入纸纹、边缘羽化、透明度高，只做氛围不抢主体。
- 主色板以莫兰迪中低饱和为基调：灰玫瑰粉 #b7897d、驼色 #cca680、灰紫、灰蓝绿 #7fa8a0、赤陶 #c26b4e、暖棕 #9c7b5a；整体灰化一度，但**允许主体局部或个别次元素用较高饱和作小面积点睛**（色彩总律见 prompt-blocks §0：色相可丰富、高饱和合计占比小、整体仍中低饱和）；大面积高饱和铺满/撞色仅在用户明确要童趣或浓郁变体时使用。

### S1-3 排版与构图（Style-1 倾向）
- 超大留白：主体常占版面 35–55%，呼吸感优先；默认主体居中。常用手法：
  1. 状态叠加（可选非默认，规则见 SKILL 第 1 步，共8种）：整颗+剖半/切片/切大块/切小丁/切条切丝/剥皮/剥壳；
  2. 垂直叠罗汉（同类 2–3 个上下堆叠）；3. 散点平衡（沿 S 形/对角散布）；4. 偏心+文字对位。
- 文字参与构图；小装饰语言：同色系 2–3 个小圆点、虚线、椭圆图章、红色小印章、A./B./C. 标号，点到为止。

### S1-4 文字的"风格性格"（规则与命令见 LAYOUT §6）
- 主标题：一律后期 PIL，从 serif/sans/kai/hand 选（**不用 marker**）；Style-1 偏温润，可用 serif 或 kai/hand，颜色取主体固有色；
- 次要文字：等宽打字机体（type），默认＝一句短诗**再加上**独立两行：季节、拉丁学名（写法见 LAYOUT §6.5），与主标题形成"手作/衬线 × 机械"对比，贴主体周围留白、与主标题对角呼吸；
- 中文模式（主标题与短诗均中文）：短诗中文、季节用中文、不生成拉丁学名；次要文字（type）含中文会自动回退到 kai 楷体，因此**主标题改用 serif（宋体）/hand（行楷）/sans、不再用 kai**，以免主、次实际同字体（主标题仍可竖排配红色小印章）；只有英文排版才用英文大写季节＋学名。
- 主/次字体必须不同；实现、排法（用户指定优先，无指定时五者随机、无默认）、位置、字号占比、自动选色等全部规则以 LAYOUT §6 为准。

### S1-5 提示词风格段
固定媒介段已抽成模块 **M1（见 prompt-blocks.md §1）**，直接拼装，不再在此另存副本；结构段按 subject-structure.md 结论追加、服务概括而非写实：
`clear layered structure with natural size variation and simple darker contact shadows where parts meet, rendered in few flat color blocks instead of fine detail`

## Style-2：叙事静物编排（笔触沿用公共段）

> 来源：45 张电影感商业静物参考（番茄×LOEWE、泳池夏日、果园香水、CHANEL 米金、VALENTINO 烛光、Trudon 红、LE LABO 橙花等）。
> **铁律：学 Style-2 的"编排语言"，画面笔触一律用公共段（M1）**——用水彩+蜡笔稚拙插画画出有叙事编排的静物剧场，**禁止画成写实照片**。主体自身的上色严格守公共段：平涂色块拼接、零深色封闭描边、色块洇虚成形、浅色留纸白；Style-2 的硬光与投影只作为**场景层的图形色块与景深虚实**存在，绝不在主体表面堆明暗渐变或细描边。

**通用规则不在此复制**：笔触克制定义见本文件公共段；背景见 LAYOUT §3；主体突出/同类疏密/边缘虚实见 LAYOUT §4（§4.1 英雄突出、§4.2 疏密、§4.3 边缘虚实是本风格最常用的三条）；文字全部规则见 LAYOUT §6（Style-2 与 Style-1 一样**每张必配主标题＋短诗**，不是无文字场景）；提示词模块见 prompt-blocks.md（M2）。本档案只写 Style-2 独有的编排手法。

### S2-1 一句话定位
一个"英雄产品/主体" + 同色天然物做成分呼应 + 一个生活容器 + 硬光投影 + 三层景深 + 明确氛围，全部以公共段稚拙水彩蜡笔笔触呈现。

### S2-2 色彩编排
> 三风格通用的色彩总律（色相丰富 ＋ 整体中低饱和 ＋ 局部高饱和点睛）见 prompt-blocks §0 PALETTE；本节只讲 Style-2 的编排配色，二者叠加生效。
- 面积：背景/环境 60–70%（低彩无彩），道具无彩色 20–30%，强调色 5–10%。
- **成分可视化（灵魂手法）**：英雄主体的颜色在一个天然物上重复一遍（红瓶↔红番茄、绿瓶↔青梨、黄液↔柠檬），强调色只此"一家人"。
- 三种配色取一：①同色系统一（靠明度拉开）②互补撞色（红蓝/蓝橙/粉绿）③邻近自然色（绿黄/米金）。
- 夜晚/烛光压暗四周属深色背景典型应用，受 LAYOUT §3 约束：英雄最亮、文字暖白、深色也轻盈通透不吞主体。

### S2-3 光影编排（用公共段色块概括，不写实）
- 单一方向硬侧光/窗光；投影边缘肯定，**影子本身是构图图形**（窗格影、百叶影、枝影）。
- 明暗两极按氛围选：夜晚/烛光→压暗四周只亮主体；清晨/洁净→高调近白。
- 英雄主体永远最亮、对比最强、唯一实焦；食材次之，环境最柔（即 LAYOUT §4.1/§4.3 在本风格的落实）。
- 光面（玻璃/瓷/水/果蜡）×哑光（纸/布/木）相邻；水与光斑可作提亮。
- 主体表面近乎平涂：只靠一块略深同色色面 ＋ 一两个小高光点交代体积（公共段 §1.3），不做三面五调；**场景里的硬光投影/窗格影本身当作一块平涂图形色块来画，边缘肯定但内部不渐变**；编排复杂度可以高、用笔数量不能多；全程零深色封闭描边，靠色块与纸白缝隙成形。

### S2-4 构图骨架（六选一或组合）
中轴对称 / 三分偏心 / 对角线 / 向心环绕（众星捧月）/ 垂直分层 / 框架遮挡（前景开"窗"窥视）。
- 可用"危险平衡"：歪斜叠高的杯盘书果在将倒未倒处静止，制造剧场张力。
- 主体占比两极皆可：英雄特写 25–40%，或藏于环境的 5% 小物（但仍须满足 LAYOUT §4.1 第一眼可辨）。

### S2-5 主次互动（叙事感来源）
- 容器承载：杯/盘/篮/水槽/书页/椅面/布兜把英雄"接住"，不悬空。
- 穿插垫靠：枝叶搭过、果实垫底、丝带系挂、花茎斜穿；**凡搭靠/缠绕必须遵守 subject-structure.md「搭靠/穿插层级规则」**——来向被主体遮挡、唯一接触点受力下弯+接触阴影、同色前后用留白轮廓/投影/点缀色分离、垂挂只在一侧、子部件独立连接，禁止像平贴在主体正面。
- 拟人/动作：给主体一个俏皮支点（果子"戴"在顶上、瓶"坐"进杯）；插画中可画一只手在倒/剥/捧，增强临场。
- 香调/成分可视化：把"气味/成分"画成同色花果食材。

### S2-6 摆放
- 不等边三角：3 个高点错落，拒绝等高等距；散点用奇数、朝向各异。
- 英雄必须一眼跳出（LAYOUT §4.1）：配料成组围绕、朝向英雄，数量再多也只是陪衬，不与英雄等大等清晰、不另立焦点。
- 同类配料有聚有散、散而不远（LAYOUT §4.2）：先收一个主簇（挨靠微叠），至多 1–2 件就近点散（≤自身 1–2 身位），禁等距摊开与远距孤点。
- "书/纸"是万能高度调节器与知性道具；重力可信：接触点、受压方向、投影成立，英雄正面朝观众。

### S2-7 三层景深（平面插画也要做出层次）
- 前景：一个虚/简的遮挡形（帘、叶、杯沿、椅背、白纱），用淡色块概括、边缘最柔。
- 中景：英雄主体，对比最强、刻画最充分、视觉权重最高（边缘按 §4.3 默认柔化，但形体最完整可辨，仍受笔触克制约束）。
- 背景：环境虚淡、色块晕染、边缘最柔；可加窗影/镜面反射/水面反光作"第四层"。
- 次元素默认比英雄柔一档、但形体与受光轮廓可辨（LAYOUT §4.3）。

### S2-8 氛围先行（先定情绪再倒推一切）
- 静谧留白 / 午后慵懒 / 清凉夏日 / 夜晚仪式 / 书卷知性 / 俏皮装置。
- 定调后再选光（暗调 or 高调）、配色（撞色 or 同色）、容器与道具。
- 道具母题：书纸、餐具杯盘、竹篮、织物丝带、水、对应花果、旧信纸。

### S2-9 提示词骨架
用模块 **M2（prompt-blocks.md §1）= M1 笔触 + 编排段**，再按序拼 HERO / CLUSTER / EDGE-DEFAULT / PROPS / BG / LIGHT / COMPOSE / TEXT / NO_TEXT（模块库 §4–12）。核心句：`[hero, its color repeated on one matching natural element], in/on a [container], [3 uneven high points + odd scattered matching elements], single hard side light with graphic [window-grid/branch] cast shadow, [one soft out-of-focus foreground shape], blurred background, [mood] narrative still life`，并反复强调 illustrative/painterly, not a photograph。

### S2-10 与 Style-1 的关系
- Style-1 = 单体静物海报；Style-2 = 有场景叙事与编排关系的静物插画；二者都是平等风格，**差别只在编排复杂度与叙事性，不在"有没有文字"**。
- 笔触、纸纹、色板一致；主标题与次要文字（短诗 ＋ 季节·拉丁学名）约束逐条完全一致、每张必配、一律后期 PIL（LAYOUT §6）。
- 完整逐张分析见 `_archive/analysis/style-2-analysis.txt`（开发存档、主流程不加载）。

## Style-3：色粉/油画棒 · 纸面颗粒

> 来源：Style-3 参考图分析报告第 4–7 点（颜色/明暗/配色/构图）。
> **定位：第三种平等静物风格，主体始终是静物**（果蔬、食物、器物、花植等），不画拟人角色、不讲故事叙事。

**通用规则不在此复制**：笔触克制定义见本文件公共段（S3 换成干擦语言）；背景颜色唯一权威见 LAYOUT §3（三风格同规则）；主体突出/同类疏密/边缘虚实见 LAYOUT §4；文字全部规则见 LAYOUT §6（Style-3 同样每张必配主标题＋短诗）；主体结构见 subject-structure.md；提示词模块见 prompt-blocks.md（M3）。本档案只写 Style-3 独有媒介与手法。

### S3-1 何时进入
用户点名 Style-3 / 色粉油画棒风 / 纸面颗粒静物 / pastel & oil-pastel still life，或在三种平等风格中按题材选到本风格。

### S3-2 媒介与质感（识别点，保持不变）
固定质感段（模块 M3）：
`soft pastel and oil-pastel still life on textured paper with visible kraft-paper grain, grainy chalky scumbled strokes so the paper fiber shows through, thick opaque crayon for light-colored objects, loose colored-pencil outlines that break and never fully close, hand-drawn warmth, NOT watercolor, NOT digital smooth, NOT photorealistic`
- 色粉/油画棒干擦：粉质飞白、叠擦肌理、边缘毛糙，颜色"擦"上不涂满；
- 浅色/白色对象用厚涂覆盖（最亮最跳），深色对象干擦叠色；彩铅/蜡笔松线勾轮廓，线不封闭、时断时续；
- **笔触克制（三风格铁律，对齐公共段 §1，只换成干擦语言）**：以**干擦平涂色块拼接造型为主**，每个部件一块固有色面（一遍扫出、允许飞白透纸与颗粒沉淀），**不勾深色封闭外轮廓、靠干擦色块自身成形**，松线只作断续提示、绝不光滑封边；散光近乎平光，体积只靠一块略深同色干擦面 ＋ 一两个小高光点，亮/暗/中间调各一两块色面说完即止，不反复叠擦磨细腻渐变、不靠堆颗粒凑细节；白色/浅色部位直接留纸白，或用浅色厚涂覆盖一遍；籽/点/斑/棱等细节用同色系更深的小色点或短干擦笔触；相邻色块靠纸白缝隙或一块略深同色面分界，不用黑线；此处"厚涂"仅指浅色对象对纸面的覆盖力，不是多层堆笔；
- **背景**：纹理默认保留牛皮纸/有色纸纤维颗粒，颜色按 LAYOUT §3（默认浅底/撞色例外/深色自选）。**牛皮纸是"质感"不是"颜色"**——经典牛皮棕 #c19a6b 只是可选之一、非必须非默认；深底时主体改奶油白等高明度厚涂跳出。无论选何色都保留"纸面颗粒+干擦+松线"的一致性。
- 台面/基线：在下 1/4–1/5 干擦一带更浅/更暖的色带，兼作台面与基线，边缘毛糙、露出纸纹。
- 边缘虚实按 LAYOUT §4.3，用干擦松线语言落实：默认主体轮廓也干擦松化、飞白断续（但比次元素更收得住、更完整可辨），次元素飞白更多、勾线更断、背光侧更多擦散进颗粒，再柔一档。

### S3-3 颜色系统
> 三风格通用色彩总律（色相丰富 ＋ 整体中低饱和 ＋ 局部高饱和点睛）见 prompt-blocks §0 PALETTE，与本节 S3 配色叠加生效。
- 面积：背景 50–60%（颜色按 LAYOUT §3，不一定是棕）；主体高明度/厚涂色 20–25%；其余主色与点缀色。
- 配色倾向：大地暖调（棕/橘/赭/苔绿/砖红）是经典选择，但背景用浅底时主体按实物固有色即可，不必限大地色。
- 一物一主色：每个静物对象一个识别主色，不混用；格纹/织物可作暖色调纽带；高饱和或冷色只作 1–2 个小面积点睛。

### S3-4 明暗关系
- 散光/柔光，无明确光源、**无硬边投影**（不画窗影/明暗交界线）。
- 体积靠"同色系深浅叠擦"：散光下主体表面近乎平涂，用同色不同明度**各一两块色面**（一块略深同色面 ＋ 一点高光）干擦带出、笔数最少，平而不扁，不叠擦出细腻渐变、不勾封闭描边。
- 对象脚下只擦一小片影/基线上的擦痕，表示落在台面上，点到为止；最强明度对比来自"主体厚涂 × 背景"，借此让主体最先被看见。

### S3-5 配色逻辑
- 主策略：邻近色/同色系求统一；次策略：一物一色靠色相区分；点睛：一张最多 1–2 个冷色/高饱和小块做视觉停顿。
- 口诀：背景托主体，配色求统一，一物一色，跳色只点一下。

### S3-6 构图原则
- 居中大留白：主体/群组居中偏下，四周大量纸面留白；低基线：一条台面色带横在下 1/4–1/5，所有物件同线、重力可信。
- 两种群组：①聚散群组（多物件横向错落、高低大小成节奏，遵守 LAYOUT §4.2 一个主簇＋近距点散）；②围合群组（主物件居中、次元素围拢向心，遵守 §4.1 英雄突出）。
- 前后靠**遮挡**不靠景深虚化：后排只露局部，前排压后排，脚前擦台面色带。
- 可出"全景+局部"配套；**局部特写主体从单侧连贯伸入、轮廓同源，禁止左右各放一块不相连同色形体（会被看成重复物件）**。
- 视角平视/微俯/俯视皆可，亲切不夸张。

### S3-7 文字（风格性格；规则见 LAYOUT §6）
- 与 Style-1/2 完全一致、每张必配主标题＋次要文字（一句短诗 ＋ 季节·拉丁学名两行）；文字一律后期 PIL（生图无字）、排法用户指定优先、无指定时五者随机（无默认）、上方居中优先、自动对比选色不融底，全部以 LAYOUT §6 为准。
- 风格性格：干擦颗粒纸面上，serif/sans/kai/hand 主标题配 type 打字机次要文字（**不用 marker**），主/次字体必须不同；中文 kai 可竖排配小印章。

### S3-8 提示词骨架
用模块 **M3（prompt-blocks.md §1）** 替换 M1，其余按序拼 SUBJECT/HERO/CLUSTER/EDGE/BG（追加低基线条）/LIGHT（散光）/COMPOSE/TEXT/NO_TEXT：
`[M3 质感段, 背景色指定为选定 color], [single still-life subject + state + real color per subject-structure], [1–2 accent props], on textured paper with a low dry-brushed ground band, [clustered/row composition, centered, generous negative space], one-object-one-color, thick light crayon against ground, soft diffused scumbled shading, no hard shadows`
文字一律后期 PIL：提示词不生成任何标题字，并在上方居中与次要文字落点预留干净区。

### S3-9 边界
只画静物，不画拟人动物/角色/故事动作；如用户要角色叙事，说明本技能不覆盖、需另行处理。完整维度分析见 `_archive/analysis/style-3-analysis.txt`（开发存档、主流程不加载；角色/叙事章节仅作来源，不构成规则）。

## 题材选型速查（无指定时的倾向，不是默认、可偏离）

> 主体固有色永远以实物为准，本表只定字体/背景/视角倾向。

| 题材 | 主标题字体 | 背景/点缀倾向 | 视角倾向 |
|---|---|---|---|
| 水果 | kai/hand | 米白纸纹＋叶绿点缀 | 俯视/平视 |
| 美食·甜点·料理 | hand/serif | 暖米/陶土灰＋餐桌木纹 | 45°/俯视 |
| 酒饮酒器（杯/瓶） | serif | 低饱和奢华灰、酒液同色系 | 平视/微仰 |
| 电商产品/器物 | sans | 品牌单色＋一块接触色，近平光零描边 | 平视/45° |
| 花植 | serif/kai | 柔色低饱和 | 俯视/平视 |
| 时尚配饰 | serif | 灰米/莫兰迪、对比克制 | 平视/俯视 |
| 建筑/风景 | serif | 天光冷灰、钢笔淡彩 | 平视/微仰 |
| 分子/科学对象 | sans | 极简单色＋一点辉光、大留白 | 等轴测/平视 |

> 酒饮/电商/分子这类要"通透或极简"的题材，靠一两块同色深浅面＋留白高光成形，不做细腻渐变、不做柔光 3D 渲染；任何题材都禁违背实物固有色、禁 AI 直出文字、禁第二主体。
