# 性能模式（正式档 vs 快速档）

> 本文件是"快速档/正式档"行为的唯一权威来源。SKILL.md 与 README.md 只引用本文件，不重复描述。

## 1. 正式档（默认）

| 项目 | 值 |
|------|-----|
| 模型 | `seedream_5.0_pro` |
| 长边 | 2048 px |
| 张数 | 双稿（A/B 视角与版式均不同） |
| 适用 | 正式成稿、交付、存档 |
| 伪文字率 | 低（对否定约束遵循好） |

**默认行为**：用户未点名时恒定走正式档，不因求快擅自降级。

## 2. 快速档（可选；仅用户点名时才走）

**触发词**："快"、"快速预览"、"先出草稿"、"草稿模式"

| 项目 | 值 |
|------|-----|
| 模型 | `seedream_4.5` |
| 长边 | 1536 px（prep 用 `--long-edge 1536`） |
| 张数 | 可只出 1 稿先看效果 |
| 适用 | 构图草稿、快速试布局、验证创意方向 |
| 生成速度 | 约快一倍 |

### 2.1 实测特性（要有预期）

- 4.5 对 `no text / no line / no frame` 等否定约束的遵循弱于 5.0
- 对"平涂色块・近平光・零描边"这类克制笔触的遵循弱于 5.0
- 可能冒出伪手写文字、装饰横线/角框
- 果实立体感可能偏强
- **常需 1–2 次重生**才干净

### 2.2 定位与限制

- 快速档**只定位为"构图草稿 / 快速试布局"**
- 此阶段**可不叠正式文字**
- **正式成稿仍回 5.0 Pro**
- 快速档的成品**不作为最终交付**

### 2.3 输出标注要求（强制）

快速档输出时必须明确标注：

> 「此为草稿（4.5 快速预览，可能含伪文字/构图偏差），如需正式高清版本请回复『定稿』，我将用 5.0 Pro 重新生成双稿正式版本。」

## 3. 模式切换流程

```
用户说"快速/草稿" → 走快速档（4.5/1536/可单稿）→ 输出草稿 + 标注
用户说"定稿/正式" → 走正式档（5.0 Pro/2048/双稿）→ 输出正式成品
用户未点名 → 默认走正式档
```

## 4. 快速档 → 正式档的迁移

当用户从快速档切换到正式档时：
1. 保留快速档验证过的 brief（主体、构图、风格等创意设定）
2. 模型切换为 5.0 Pro
3. 长边恢复为 2048
4. 恢复双稿（A/B 视角与版式均不同）
5. 叠正式文字
6. 输出正式成品
