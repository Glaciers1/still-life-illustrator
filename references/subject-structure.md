# 主体结构分析（写提示词前必做）

> **结构为骨，概括为法，明暗有度，笔触最少**：分析要深入（避免图标式机械），表现要克制（避免照片式写实），光影要保留（避免死平涂），用笔要最省（避免碎笔堆渐变）。
> 结构结论用于安排层级、遮挡、接触阴影与大小节奏；落笔以**平涂色块拼接造型、不勾深色封闭描边**（靠色块自身边缘成形、浅色部位直接留纸白），典型特征可识别即可；近乎平光，体积只靠一块略深同色色面 ＋ 一两个点到为止的小高光、交叠处一块接触深色，亮/暗/中间调合并成最少的一两块色面说完，不多层渲染、不排笔叠色、不做光滑细黑描边。细节可取舍但体积不可全废，笔触数量能少一笔是一笔（笔触克制的完整定义见 style-profiles.md 公共段，本文件只在结构语境下强调）。
>
> 避免四个极端：部件等大等距正圆的"图标感"；粒粒高光纤毫毕现的"写实感"；毫无明暗的"平涂感"；碎笔层层叠加磨出细腻光影的"渲染感"。

## 分析清单

1. **整体形态与生长方式**：几何结构是什么？（葡萄串是下宽上窄的圆锥塔状果穗，不是平面圆球堆；洋葱是球茎+外皮；芭乐是球形果实对半切）
2. **层级与纵深**：分几层前后关系？谁挡住谁？前景物轮廓完整，后景物只露出弧形局部（"half-hidden, only a curved sliver showing"）。
3. **遮挡、挤压与接触阴影**：相邻部件接触处会互相挤压变形——葡萄颗粒接触面微扁，绝非颗颗正圆相切；**每一处交叠、缝隙、接触点都要画更深、更饱和的接触阴影 / AO**（如两瓣芭乐相交处的深色缝线、葡萄串缝隙里的深苔绿），边缘略虚。
4. **大小与朝向变化**：自然物尺寸服从分布而非统一：颗粒间差 15%–30%，小果嵌在大果之间；朝向各异，但**所有高光必须来自同一光源方向**。同类多件还要有**疏密节奏**：多数聚拢成一个主簇、极少量就近点散，不等距摊开、不远离主簇（细则见 SKILL 全局铁律"主体突出与同类疏密"）。
5. **表面细节**：果粉/白霜、果点、皮孔、脉络、纤维、籽、切面纹理、果皮厚度、汁水反光、木质枝梗纹理。
6. **不完美感**：轻微疤痕、斑点、不对称、自然下垂的重量感（"heavy, drooping slightly under its own weight"）。
7. **繁简控制**：部件数量够成立即可（一串葡萄看得出是一串即可，不数颗粒），把笔墨留给轮廓与色块，不主动加疤痕、水珠、籽、纤毛等碎节（用户点名才画）。

## 提示词转译示例（葡萄）

不要只写 "a bunch of grapes"，也不要堆砌写实细节。结构到位、色块概括：

> a natural conical bunch of green grapes in a few overlapping layers, berries vary slightly in size with simple darker green contact shadows where they meet, suggested with a few flat muted-green color blocks and minimal strokes, no glossy highlights, simple woody stem, instantly readable as grapes

## 常见主体结构速查（识别特征，点到为止）

| 主体 | 结构要点（只需保留的识别特征） |
|---|---|
| 葡萄/浆果串 | 塔状串形、几层遮挡、大小微差、接触处简单深色、一枝木质梗；状态叠加三风格通用：可整串+切片/散粒同框（算一个主体类别），切片露果肉与籽 |
| 柑橘类 | 圆形+果蒂一点；切面题材才画放射瓣 |
| 芭乐/苹果/梨 | 球形+果蒂凹陷；切面题材才画籽芯与相交深色缝线 |
| 洋葱/蒜 | 球茎+尖芽+根须；外皮色块概括纹路 |
| 桃/李/番茄 | 圆形+一条果沟+果蒂萼片 |
| 花卉 | 几层花瓣螺旋+中心花蕊，内侧一色深影 |
| 叶菜/草本 | 叶片+主脉+茎，不画虫洞水珠等碎节 |
| 坚果/豆荚 | 外壳形状+一道开裂缝 |

## 搭靠 / 穿插 / 缠绕的层级规则（主体与次元素接触时必查）

当枝、藤、绳、布、手等"搭 / 绕 / 挂 / 靠 / 垫"在主体上时，物理层级必须可信，不能像"贴"在主体正面：

1. **来向与去向闭环**：搭靠物从画面外或主体后方来，经过接触点再离去；被主体挡住的段落不画（或只露尖端），交代清楚"谁在谁后面"。
2. **唯一接触点 + 受力形变**：搭过肩/沿处只有一个接触点，枝条在该点因重量轻微下弯；接触点画一小片更深更饱和的接触阴影。
3. **同色前后分离三招**（当前景物与主体同色/近色时，如红果搭红瓶，最易糊成一片）：①前景物边缘留一丝纸白/浅色轮廓线；②前景物在主体表面投一小片柔和投影；③用点缀色（果蒂绿、小高光、异色勾边）把前景物"提"出来。
4. **垂挂只在一侧、数量克制**：果串/布垂下时集中在主体一侧，不铺满正面；看得出是一串即可，不数颗粒。
5. **子部件独立连接**：每颗果实有自己的细梗连回主藤，每片叶连回茎，而非直接粘在主体表面。

## 反面 → 正面措辞

- "均匀的一串" → "berries vary slightly in size, natural rhythm"
- 无接触阴影 → "simple darker color where parts meet"
- 颗颗正圆 → "soft irregular rounded shapes"
- 平面铺开 → "a few overlapping layers suggested by color blocks"
- 照片写实 → "flat color blocks assembled into the shape, no closed outline, one slightly deeper same-hue block plus a tiny highlight or two, dimensional but not detailed"
- 死平涂 → "one slightly deeper same-hue block on the overlap/shadow side, a tiny highlight, a soft contact shade beneath"
