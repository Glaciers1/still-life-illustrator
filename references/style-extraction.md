# 参考图风格提取

## 目录
1. 何时提取
2. 提取维度与输出表
3. 无参考图兜底

## 1. 何时提取
输入含图片时必做。先 `scripts/inspect_image.py` 取客观参数，再 Read 图片做视觉提取；多张参考图时，一张定版式、其余定风格，冲突时以用户指定为准。

## 2. 提取维度与输出表
向用户展示如下表格（提取不到的维度写“未出现”，并给出兜底选择）：

| 维度 | 提取内容 | 在新插画中的用法 |
|---|---|---|
| 主体 | 对象名称、数量级、材质、成熟度/状态 | 决定唯一主体与固有色 |
| 固有色 | 主体真实颜色区间（成熟红/未成熟青绿等） | 提示词颜色约束，禁止违背常识用色 |
| 笔触质感 | 水彩/彩铅/油画/平涂矢量/钢笔淡彩/噪点肌理… | 风格关键词与模型选择 |
| 色板 | 主色+辅色各取 HEX（来自 inspect 主色） | 背景、次元素、文字颜色 |
| 背景纹理 | 纸张颗粒/布纹/纯色/渐变/桌面木纹 | 背景描述；纹理优先沿用参考图 |
| 排版方式 | 居中/偏心/包围、文字区方位 | 主体摆位与文字区预留 |
| 构图规则 | 三分/黄金分割/对角/二八/对称 | 提示词构图关键词 |
| 主标题 | 原文、语言、字数、字体风格（手写/衬线/无衬线/艺术体） | overlay_text 主标题字体依据 |
| 次要文字 | 原文、字号层级、颜色、位置 | overlay_text 副标题；其字体成为默认次要字体 |
| 视角 | 俯视/平视/45°/仰视 | 两稿视角分化依据 |

注意：参考图中的文字只提取“风格与字体类型”，不复制其原文案；新文案由用户需求或主体题材决定。

## 3. 无参考图兜底
- 按 SKILL 第 2 步在三种平等风格中择一（用户未指定则按题材选最合适者并说明理由）；需要稳妥基线时，Style-1（白棉纸纹底、水彩+蜡笔稚拙笔触、莫兰迪色）最通用；
- 题材微调查 SKILL「步骤 2 · 题材选型速查」；
- 构图：两稿只要求视角、版式各不相同，**无默认组合**，按主体形态与画面美感灵活搭配（俯视/平视/45°/仰视 × 居中/三分/对角/散点）；
- 文字：主标题与次要文字一律后期 PIL、生图无字（规则见 `layout-and-composition.md §6`）；主标题用 serif/sans/kai/hand（不用 marker，颜色取主体色），次要文字用 type 打字机体，含一句短诗 ＋（空行分界、2.5 倍字高段距）季节块：英文排版为英文大写季节＋大写学名两行，中文排版（主标题与短诗均中文）只一行中文季节、无学名（见 LAYOUT §6.5）；中文主标题 kai；主/次字体必不同。
