# 物产知识库 ·《旬物索引》（静物插画师 · 四季应季物产与全年常备全录）

> **定位**：本文件是静物插画技能的**题材事实知识库**，收录四季应季作物、鲜食、香草、花卉、谷物、甜点烘焙及器物共 **374 种**，按「春 37 / 夏 69 / 秋 42 / 冬 28 / 全年·常备 198」五区组织；全年区下设器物用具、甜点烘焙、花卉、常备食材四组。每条给出：**固有色 / 质感 / 结构 / 分布 / 原产地 / 成熟（应季）/ 搭配器皿 / 入画风格建议**，用于支撑「主体结构分析（固有色·形态·细节）、应季季节判定（§6.5.2）、风格与道具/器皿选择」。
>
> **怎么用（按需检索、不要全量通读）**：在「解析输入 / 设计推演 / 主体结构分析 / 定季节」时，用 Grep 检索主体或搭配物名称，只 Read 命中的那几条即可；多物件就各取一条，不整卷加载。四季区按真实应季月份归位，全年可得、无明显应季窗口的器物 / 甜点 / 花卉 / 常备食材统一归入「全年 · 常备」区。
>
> **边界（不覆盖 SSOT 铁律）**：
> - 本文件只提供题材事实与倾向，**不改变**笔触/构图/边缘/色彩/文字等任何铁律与流程（权威仍在 SKILL.md、layout-and-composition.md、style-profiles.md）；
> - 每条末尾「入画：S1/S2/S3…」仅是**题材倾向建议**，最终风格仍按 SKILL 决策树（用户点名＞参考图＞题材）定；
> - 「成熟」字段是判定**应季季节词**的事实依据之一，但季节词与中英写法、两稿统一仍以 `layout-and-composition.md §6.5.2` 为唯一权威；全年区题材被选中时，季节词按当批设定或画面语境取四季之一；
> - 本库**不含拉丁学名**，学名一律按 `layout-and-composition.md §6.5.2` 核实、不臆造。
>
> **字段含义**：固有色＝真实固有配色（PALETTE 依据）；质感＝表面肌理（笔触/颗粒依据）；结构＝形态尺寸与识别点（subject-structure 依据）；成熟＝应季月份（季节词依据，写「全年」者入全年区）；搭配＝推荐器皿与同框物（道具/次元素依据）；入画＝风格与状态叠加倾向。

## 春 · Spring（37 种）

### 草莓
**固有色**：朱红底金黄籽，蒂嫩绿。**质感**：细密颗粒，受光瓷光。**结构**：心形，径3-5cm。**成熟**：露地5-6月，温室2-4月。**搭配**：素白浅碗、粗陶小盆、竹编提篮。

### 芦笋
**固有色**：嫩绿至淡紫渐变，尖端微紫。**质感**：滑润带浅棱。**结构**：茎长15-25cm，笔直微锥。**成熟**：4-6月。**搭配**：白瓷长盘、木砧板。

### 豌豆
**固有色**：荚鲜绿，粒翠圆。**质感**：荚面光滑略硬。**结构**：荚长6-10cm，每荚5-8粒。**成熟**：4-6月。**搭配**：搪瓷碗、小木碗。

### 洋蓟
**固有色**：苞片灰绿带紫晕，心嫩黄。**质感**：苞片硬肉质。**结构**：球状花蕾，径8-12cm。**成熟**：春季3-5月，秋二次花。**搭配**：深口白陶碗、木质托盘。

### 郁金香
**固有色**：红/粉/黄/白/紫单色或条纹。**质感**：蜡质绸缎光泽。**结构**：杯状花冠，高20-40cm。**成熟**：3-5月花期。**搭配**：透明玻璃瓶、素烧陶罐。

### 春笋
**固有色**：外壳淡褐带紫纹，内嫩白微黄。**质感**：外披细毛，剖开脆嫩多汁。**结构**：锥形，高15-30cm。**成熟**：3-5月。**搭配**：竹编笼屉、深色陶锅。

### 薄荷
**固有色**：鲜绿，叶脉凹纹。**质感**：叶微皱，边缘细锯齿。**结构**：叶对生，茎四棱，高30-60cm。**成熟**：春至秋季，嫩叶4-6月最佳。**搭配**：素白瓷杯、玻璃水罐。

### 食用花（三色堇/金盏菊/琉璃苣）
**固有色**：紫/白/黄/蓝等明艳色。**质感**：花瓣柔嫩薄透，有丝光感。**结构**：小花径2-5cm，单瓣或重瓣。**成熟**：春至初夏。**搭配**：白瓷平盘、玻璃浅碗。

### 蚕豆
**固有色**：荚深绿，内白绒，粒嫩绿。**质感**：荚面绒毛，粒皮光滑。**结构**：荚长8-12cm，每荚2-4粒。**成熟**：4-5月。**搭配**：粗陶浅碗、竹编笸箩。

### 香椿
**固有色**：嫩芽紫红/深褐，芽尖微绿。**质感**：芽叶柔嫩，茎脆。**结构**：顶芽簇生，长5-12cm。**成熟**：清明至谷雨（4月上中旬）。**搭配**：竹编小篮、白瓷浅盘。

### 莴笋
**固有色**：茎皮浅绿/白绿，叶深绿。**质感**：茎肉脆嫩多汁，表皮光滑。**结构**：茎棒状，高20-40cm。**成熟**：4-6月。**搭配**：木砧板、白瓷长盘。

### 春韭
**固有色**：叶鲜绿，叶鞘白/淡紫。**质感**：叶扁软，掐断有水。**结构**：丛生，叶长20-40cm。**成熟**：3-5月（头刀韭最香）。**搭配**：粗陶小盆、竹编笸箩。

### 荠菜
**固有色**：叶深绿/灰绿，根白。**质感**：叶柔皱，贴地生长。**结构**：莲座状，高10-20cm。**成熟**：3-4月。**搭配**：竹编浅筐、搪瓷盆。

### 紫藤
**固有色**：淡紫/蓝紫渐变，花蕊黄。**质感**：花瓣薄如蝶翼，花序垂坠。**结构**：总状花序，长20-40cm。**成熟**：4-5月花期。**搭配**：素陶长颈瓶、青瓷瓶。

### 樱花
**固有色**：白/淡粉/粉红，花蕊深粉。**质感**：花瓣薄透有绢光。**结构**：伞形花序，径2-5cm。**成熟**：3-4月花期。**搭配**：玻璃细瓶、素烧陶瓶。

### 樱桃萝卜
**固有色**：皮鲜红/紫红，肉白。**质感**：表皮光润，肉质脆嫩。**结构**：球状，径2-4cm，缨翠绿。**成熟**：4-6月。**搭配**：白瓷浅盘、木砧板。

### 水芹
**固有色**：茎绿/白绿，叶深绿。**质感**：茎中空脆嫩。**结构**：高20-50cm，水生。**成熟**：3-5月。**搭配**：白瓷浅盆、搪瓷盆。

### 艾草
**固有色**：叶背灰白，面深绿。**质感**：叶柔毛，揉有浓香。**结构**：羽状深裂，高30-80cm。**成熟**：清明前后（4月上旬）。**搭配**：竹编浅筐、粗陶小盆。

### 青团
**固有色**：表皮深绿/墨绿，内馅暗红/黑。**质感**：外皮软糯微黏，内馅绵沙。**结构**：圆扁形，径4-7cm。**成熟**：清明前后。**搭配**：竹蒸笼、白瓷浅盘。

### 早春蜂蜜（油菜/洋槐蜜）
**固有色**：浅琥珀/淡金黄，半透明。**质感**：浓稠流蜜状，挂壁慢。**结构**：瓶装液状。**成熟**：4-5月。**搭配**：粗陶蜜罐、玻璃小瓶、蜂巢块。

### 白芦笋
**固有色**：通体象牙白/淡黄，尖端微紫。**质感**：表皮细滑，肉质脆嫩。**结构**：茎长15-25cm，笔直。**成熟**：4-6月（培土遮光）。**搭配**：白瓷长盘、木砧板。

### 牡丹
**固有色**：深红/粉/白/紫，花蕊金。**质感**：花瓣厚实重瓣，绢缎光泽。**结构**：花径10-20cm。**成熟**：4-5月花期。**搭配**：素陶大瓶、青瓷瓶。

### 青花鱼
**固有色**：背蓝黑虎斑，腹银白，肉粉红。**质感**：皮紧滑，肉紧实。**结构**：长圆梭形，长25-40cm。**成熟**：4-6月。**搭配**：木质砧板、白瓷浅盘。

### 平菇
**固有色**：菌盖灰褐至深灰，菌褶白，边缘薄。**质感**：菌盖柔韧滑润，边缘薄而卷。**结构**：扇状或贝壳形，盖径5-15cm，盖面光滑。**成熟**：全年，春秋两季野生。**搭配**：竹编笸箩、粗陶浅碗、木砧板。

### 杏鲍菇
**固有色**：菌盖浅灰褐，菌柄乳白至淡黄。**质感**：菌盖紧实，菌柄肉质肥厚。**结构**：棍棒状，柄长10-20cm，盖径3-6cm，盖小柄粗。**成熟**：全年，春季最肥。**搭配**：木砧板、白瓷长盘、粗陶浅盆。

### 羊肚菌
**固有色**：菌盖深褐至黑褐，蜂窝状凹陷，菌柄米白。**质感**：菌盖干脆有蜂窝孔，菌柄中空。**结构**：圆锥状，盖高4-8cm，柄长2-5cm，盖面蜂窝格。**成熟**：3-5月。**搭配**：素白浅碟、粗陶小碗、木砧板。

### 桑葚
**固有色**：紫红/深紫/白，细长聚合果。**质感**：果粒柔软多汁，表面有细粒凸起。**结构**：长圆柱形，长2-4cm，由多小核果聚成。**成熟**：5-6月。**搭配**：白瓷浅碟、木盘、竹编篮。

### 茶树菇
**固有色**：菌盖深褐至红褐，菌褶白，菌柄浅褐。**质感**：菌盖干滑，菌柄纤维韧。**结构**：细长伞状，盖径2-5cm，柄高5-12cm。**成熟**：春秋两季。**搭配**：竹编笸箩、粗陶浅碗、木砧板。

### 枇杷
**固有色**：外皮橙黄/浅黄带细绒毛，果肉橙黄。**质感**：表皮薄软带绒，果肉软甜多汁。**结构**：卵形/球形，长3-5cm，径2-4cm。**成熟**：5-6月。**搭配**：白瓷浅碗、木盘、竹编篮。

### 马蹄莲
